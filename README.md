# 梯田秋收机械协同

协调梯田收割、单轨转运、烘干和入库的设备与粮食批次。

## 领域资料

`contracts/domain.schema.json` 记录共享资料结构，`fixtures/domain.json` 是不含真实个人信息的示例。参与方包括农机中心调度员、种植合作社、设备操作人员、粮食品质人员。

当前资料依据以下业务事实维护：

- 当地使用山地单轨运输车解决梯田运粮困难
- 秋收期间调配六十余台联合收割机并包含外省设备
- 稻谷需连续烘干并把水分控制在安全储存标准内

## 协同服务模块

- `src/store.js` — 追加式事件日志,每条记录一行 JSON,重启后按顺序重放恢复状态
- `src/service.js` — 秋收协同服务:
  - 地块登记(成熟度、坡度、预计产量、可达设备、最晚完成时间)与设备登记(收割机、单轨区段载重、烘干仓容量)
  - 作业计划:交接链从收割到入库,约束收割机班次、单轨区段互斥与载重、转运批次、烘干仓容量与连续处理时长
  - 称重、设备停机、降雨停工、跨村调机、品质复测等事件按发生顺序追加
  - 抢占同一设备或仓位的请求由事务裁决,整体成功或整体拒绝,不留半份预约
  - 临时改派只释放尚未开始的资源;已装载粮食的交接链必须到达明确去向(入库)
  - 角色权限:合作社只能确认自己的地块与批次,调度员处理全局冲突,质检人员独立记录入库水分
  - 调度查询:批次当前位置与下一台设备、延期影响的地块、是否达到安全储存标准(含水率 ≤ 13.5%)

## 开发命令

- 运行测试：`npm test`
- 编译或构建：`npm run build`

上述命令只读取仓库内文件，不连接外部业务服务。
